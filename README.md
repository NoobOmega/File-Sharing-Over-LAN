## 概述
基于手机热点的局域网P2P文件传输协议，无需联网，
tcp协议，不加密(因为手机热点局域网传输默认大家都是好人)
使用python实现。
# 版本规划
*v1.0*: 实现电脑端互通

*v2.0*：实现手机端和电脑端互通（目前）

*V3.0*：实现手机互通

内部版本可能逐渐实现不同系统之间的互通。

# v1.1实现思路
### 基于windows环境的文件电脑端互传
0. 前期准备：
准备ucp套接字s0，绑定udp端口11450，绑定手机热点ip(用户可选)，用于周期发送心跳包。
准备tcp套接字s1，绑定进程端口11451，绑定手机热点ip（用户可选），用于文件传输
1. 通过周期广播“H1”心跳包发现周围上线主机，收到“H1”回复“H2”，以便互相确认。
2. 确认后，用户输入或点击“目标主机”，然后输入(或浏览)文件路径，调用tcp传输文件。用户可选保存的目录。(默认当前目录)
3. 添加调试日志

## V1.1（已实现）
Windows 电脑端互传：
- UDP:11450 周期广播/收发心跳包（H1/H2）用于发现在线主机
- TCP:11451 点对点传文件（保存到接收端的“保存目录”，默认当前目录）
- UI：展示发现主机列表、选择/输入目标IP、选择文件并发送

### 运行方式（Windows）
1. 两台电脑都连接同一个手机热点（或同一局域网）。
2. 在两台电脑上分别运行：
	- 双击 `run.ps1`，或
	- 命令行执行：`python app.py`（或 `py -3 app.py`）
3. 首次启动建议先点“启动发现/接收”。


### 本机IP（热点IP）怎么填
优先选择“本机IP(热点IP)”下拉框里属于手机热点网段的那个 IPv4（例如 192.168.x.x / 172.16-31.x.x / 10.x.x.x）。

如果你不确定：
- 先在 Windows 的“设置 → 网络和 Internet → Wi‑Fi(或以太网) → 硬件属性”里看 IPv4 地址
- 或直接选 `0.0.0.0`（监听所有网卡）。

### 常见问题
- 发现不到主机：检查两台电脑是否在同一热点；Windows 防火墙是否拦截了 UDP 11450。
- 能发现但传不了：通常是 TCP 11451 被防火墙拦截；允许 Python 通过专用网络，或放行 11451 端口。
- 端口被占用：11450/11451 被其它程序占用时会启动失败；关闭占用进程或换端口（当前版本端口固定）。

### Linux 运行
1. 安装依赖（以 Ubuntu/Debian 为例）：
	 - `sudo apt-get update`
	 - `sudo apt-get install -y python3 python3-tk`
2. 运行：
	 - `bash run.sh`，或 `python3 app_linux.py`

### 使用 PyInstaller 打包
说明：PyInstaller 需要在目标系统上分别打包（Windows 产出 exe，Linux 产出 ELF）。

- Windows：
	- `pip install pyinstaller`
	- 运行 `build.ps1`
	- 产物：`dist/lan-file-transfer.exe`

- Linux：
	- `pip3 install pyinstaller`
	- `bash build.sh`
	- 产物：`dist/lan-file-transfer`

## V2.0（已实现）
### 功能
- 模式选择：电脑之间 / 手机与电脑之间 / 手机之间（开发中）
- 手机与电脑之间：电脑端启动 Web 服务，生成 URL + 二维码；手机扫码后在浏览器里可“上传/下载”
- 电脑端可添加多个“分享文件”，网页端会显示对应的下载链接（按文件逐个下载）

### 使用方法（手机与电脑之间）
1. 电脑连接手机热点（或同一局域网），运行程序（Windows 双击 `run.ps1` / Linux 执行 `bash run.sh`）。
2. 顶部模式选择“手机与电脑之间”。
3. 选择“本机IP(热点IP)”为手机热点分配的那个 IP（必须是具体 IP，不能选 0.0.0.0）。
4. 点击“启动Web服务”，会显示 URL 与二维码。
5. 手机扫码二维码，打开网页：
	- 点“上传”可把手机文件上传到电脑（保存到电脑端设置的“保存目录”）
	- 在“下载”区点击某个文件的“下载”即可从电脑下载该文件

### 使用方法（电脑之间）
模式选择“电脑之间”，用法同 V1.1/V1.2：启动发现/接收，添加文件列表，一键传输。
